# 야자 관리실

EBS 자기주도학습센터를 이용하지 못하는 학생도 야간자율학습 시간을 관리형 독서실처럼 관리받을 수 있게 만든 웹앱입니다.
인터넷 주소로 열고 휴대폰 홈 화면에 **앱처럼 설치**해서 씁니다. 학생은 자기 계정으로 기록을 쌓고, 선생님(관리자)은 학생들의 기록을 한 화면에서 봅니다.

**앱 주소:** https://kdy47736190-lgtm.github.io/yaja-room/

## v2에서 바뀐 점

- **로그인**: 학생 계정과 선생님(관리자) 계정이 나뉩니다. 기록은 학교 서버(구글 시트)에 저장되어 다른 기기에서 로그인해도 그대로 보입니다.
- **홈 화면**: 맨 위에 **최종 목표**(D-day, 과목별 목표 등급), 그 아래 **이번 주 목표**가 카드로 보입니다. 목표 카드의 **공부 시작**을 누르면 그 목표를 위한 공부가 시작됩니다.
- **5% 단위 기록**: 공부를 끝낼 때 "이번에 할 일"을 몇 % 했는지(할 일 달성도)와 주간 목표 전체 진행률을 5% 단위로 기록합니다. 진행률이 100%가 되면 목표 달성으로 표시됩니다.
- **자세한 통계**: 주간·월간 전환, 날짜별 과목 누적 막대, 달력, 그날의 공부 기록, 과목별·시간대별 분석, 할 일 달성도 분포, 계획 정확도, 방해 요인, 카메라 기록, 다음 주 제안, AI 코멘트.
- **선생님 화면**: 반 전체 현황, 살펴볼 학생 자동 표시, 학생별 상세 기록, 비밀번호 초기화와 계정 정지, CSV 내보내기(익명 가능).

통계에서 보이는 것

| 항목 | 계산 방법 |
|---|---|
| 순공 시간, 공부한 날 | 타이머의 공부 시간 합. 휴식은 빼고, 앱을 벗어난 시간·카메라 자리 비움은 학생이 고르면 뺍니다 |
| 할 일 달성도 | 공부를 끝낼 때 학생이 고른 값(0~100%, 5% 단위)의 평균 |
| 주간 목표 달성 | 진행률 100%가 된 목표 수 / 그 주의 목표 수 |
| 평균 집중도 | 끝낼 때 학생이 스스로 매긴 1~5점의 평균 |
| 앱 이탈 비율 | 공부 중 다른 앱으로 나간 시간 / 공부 시간 |
| 시간대별 | 순공은 시작~끝 사이 시간대에 고르게 나누고, 집중도는 시작 시각 기준 |
| 계획 정확도 | 할 일을 90% 넘게 한 공부에서, 실제 시간이 예상 시간보다 몇 % 더(덜) 걸렸는지 |
| 다음 주 제안 | 위 숫자에 정해진 규칙을 적용해 만든 제안(근거 숫자를 함께 표시). 효과가 검증된 처방은 아닙니다 |

## 1. 학교 서버 만들기 (처음 한 번, 선생님 계정으로)

로그인, 기록 저장, 선생님 화면, AI 멘토가 모두 이 서버 하나로 돌아갑니다. 서버 주소를 넣기 전에는 로그인 화면의 **체험하기**로만 둘러볼 수 있습니다.
학생 개인정보가 저장되므로 **선생님(학교) 구글 계정**으로 만들어 주세요.

1. 구글 시트를 새로 만듭니다(예: `야자 관리실 운영`).
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 원래 있던 코드를 모두 지우고 `apps-script/Code.gs` 내용을 붙여 넣은 뒤 저장합니다.
4. 왼쪽 **프로젝트 설정(톱니)** → 아래쪽 **스크립트 속성** → **스크립트 속성 추가**에서 가입 코드를 넣습니다.

| 속성 | 값 | 필수 |
|---|---|---|
| `JOIN_CODE` | 학생 가입 코드. 학생들에게만 알려 줍니다 | 필수 |
| `ADMIN_CODE` | 선생님(관리자) 가입 코드. **학생에게 알려 주면 안 됩니다** | 필수 |
| `ANTHROPIC_API_KEY` | AI 멘토용 Claude API 키 (아래 3번) | 멘토를 쓸 때 |

5. 오른쪽 위 **배포 → 새 배포** → 유형 선택(톱니)에서 **웹 앱**을 고릅니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
6. **배포**를 누르고 권한을 허용합니다. "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 누릅니다.
7. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다. 브라우저로 이 주소를 열어 `"joinCode":true,"adminCode":true`가 보이면 설정이 끝난 것입니다.
8. GitHub 저장소에서 `config.js`를 열고 연필(편집) 버튼을 눌러 `serverUrl: ''`의 따옴표 안에 주소를 붙여 넣은 뒤 **Commit changes**를 누릅니다. 1~2분 뒤 앱에 반영됩니다.
9. 앱에서 **처음이에요 (가입)** → 가입 코드에 `ADMIN_CODE`를 넣어 선생님 계정을 먼저 만듭니다. 학생들은 `JOIN_CODE`로 가입합니다.

> `Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포**를 해야 같은 주소에 반영됩니다. "새 배포"를 하면 주소가 바뀌니 주의하세요.
> 예전(v1) 서버를 이미 만들었다면 같은 방법으로 코드만 바꾸고 `JOIN_CODE`, `ADMIN_CODE`를 추가하면 됩니다. v1의 `점검기록`, `할일` 탭은 더 이상 쓰지 않습니다.

### 시트에 저장되는 것

시트에 탭이 자동으로 생깁니다. 사람이 읽기 쉬운 열과, 앱이 기록을 그대로 되살리는 데 쓰는 마지막 `json` 열이 함께 있습니다. **`json` 열과 ID 열은 고치지 마세요.**

| 탭 | 한 줄 | 주요 열 |
|---|---|---|
| `사용자` | 계정 하나 | 학번(아이디), 이름, 반, 역할, 상태(사용·정지), 비밀번호 해시, 가입일, 마지막 접속 |
| `학생설정` | 학생 하나 | 최종 목표, 과목, 설정 (json) |
| `공부기록` | 공부 한 번 | 날짜, 시작·종료, 과목, 주간 목표, 이번에 할 일, 예상(분), 순공(분), 할 일 달성도(%), 목표 진행률(%), 집중도, 방해요인, 실험단계 |
| `주간목표` | 목표 하나 | 주 시작일, 과목, 목표, 목표 시간, 진행률(%), 상태 |
| `시험` | 시험 하나 | 날짜, 종류, 시험 이름, 등급(백분위) |

- 앱은 기록을 먼저 기기에 저장하고, 인터넷이 연결되면 서버로 올립니다(오른쪽 위 `저장됨` 표시). 와이파이가 끊겨도 공부 기록은 사라지지 않습니다.
- 같은 기록을 두 기기에서 고치면 나중에 고친 쪽이 남습니다.

## 2. 계정과 개인정보

- 비밀번호는 원문을 저장하지 않고, 소금(salt)을 섞어 여러 번 해시한 값만 저장합니다. 로그인 상태는 서명된 토큰으로 30일 동안 유지됩니다. 비밀번호를 5번 틀리면 10분 동안 로그인이 막힙니다.
- 학교 프로젝트 수준의 보안이므로 **다른 사이트에서 쓰는 비밀번호를 쓰지 말라고** 안내해 주세요.
- 비밀번호를 잊은 학생은 선생님 화면 **계정 → 비밀번호 초기화**로 6자리 임시 비밀번호를 받아 로그인한 뒤 **내 정보**에서 바꿉니다.
- 선생님이 볼 수 있는 것: 최종 목표, 주간 목표, 공부 기록(과목, 할 일, 시간, 달성도, 집중도, 방해 요인, 카메라 판정 횟수), 성적.
- 선생님이 볼 수 없는 것: 공부를 끝낼 때 쓴 **메모**, **AI 멘토 상담 요약과 약속**(서버가 관리자에게 보내지 않음), 멘토 대화창 내용(기기에만 있음), 카메라 영상(어디에도 저장하지 않음).
- 가입할 때 이 내용을 보여 주고 확인 체크를 받습니다. 베타 테스트를 한다면 참여 동의서도 따로 받아 주세요.
- 학생이 로그아웃하면 그 기기에 남은 기록과 멘토 대화가 지워집니다(서버의 기록은 그대로).

## 3. AI 멘토 연결

멘토는 Claude API를 씁니다. **API 키는 Apps Script의 '스크립트 속성'에만 넣고, 앱 파일이나 GitHub, 메신저에는 절대 넣지 마세요.**

1. API 계정과 결제는 **선생님(성인)이** 만들어 주세요. Anthropic 서비스는 만 18세 미만이 직접 쓸 수 없고, 미성년자가 쓰는 서비스에 API를 넣을 때는 안전장치와 'AI를 쓴다는 사실 고지'가 필요합니다. 이 앱은 처음 쓸 때 무엇이 AI로 전달되는지 알리고 동의를 받으며, 멘토 규칙에 위기 상황 안내(109, 1388, Wee클래스)를 넣어 두었습니다.
2. 스크립트 속성에 다음을 넣습니다.

| 속성 | 값 | 필수 |
|---|---|---|
| `ANTHROPIC_API_KEY` | Claude API 키 | 필수 |
| `MENTOR_DAILY_LIMIT` | 학생 한 명이 하루에 보낼 수 있는 질문 수 (기본 30) | 선택 |
| `MENTOR_GLOBAL_LIMIT` | 전체 하루 질문 수 (기본 400) | 선택 |
| `MENTOR_MODEL` | 사용할 모델 (기본 `claude-haiku-5-5`) | 선택 |
| `ANTHROPIC_WORKSPACE_ID` | 키를 만들 때 워크스페이스를 고르지 않았다면 `wrkspc_…` 값 | 경우에 따라 |

3. 브라우저로 웹 앱 URL을 열었을 때 `"mentor":"ready"`가 보이면 연결된 것입니다.
4. 결제는 선불 크레딧 방식이라, 자동 충전(auto-reload)을 켜지 않으면 충전한 금액 이상은 쓰이지 않습니다. 하루 제한 값을 학교 예산에 맞게 정하세요.

멘토에게 전달되는 것: 최종 목표, 주간 목표와 진행률, 공부 기록(과목, 할 일, 예상·실제 시간, 할 일 달성도, 집중도, 방해 요인), 시간대별 집중도, 카메라 판정 횟수, 성적과 목표 등급, 지난 상담 요약과 약속, 멘토에게 쓴 대화.
**이름·학번·공부 메모·카메라 영상은 보내지 않고, 대화 내용은 시트에 저장하지 않습니다.**

## 4. 휴대폰에 앱으로 설치하기

- **안드로이드(Chrome)**: 앱의 "앱 설치하기" 버튼을 누르거나, 메뉴(⋮)에서 **앱 설치**를 고릅니다.
- **삼성 인터넷**: 주소창의 설치 아이콘을 누르거나, 메뉴에서 홈 화면에 추가합니다.
- **아이폰(Safari)**: 아래쪽 공유 버튼에서 **홈 화면에 추가**를 고릅니다. 아이폰은 Safari에서만 설치할 수 있습니다. 설치한 앱에서는 한 번 더 로그인해야 합니다.

## 5. 카메라 관리

- 공부를 시작할 때 **카메라 관리 같이 켜기**를 체크하거나, 타이머 화면의 **카메라 관리 켜기**를 누르면 앞쪽 카메라로 얼굴을 확인합니다. https 주소에서만 동작합니다.
- 판정 기준(내 정보에서 민감도 변경 가능)
  - **졸음**: 눈 감김 점수가 기준을 넘은 상태가 3초(보통) 이어지면. 고개를 25도 넘게 숙이고 있으면(필기 중일 수 있음) 3배 더 오래 지켜본 뒤 판정합니다.
  - **엎드림**: 고개를 숙이거나 눈이 감기다가 얼굴이 사라진 채 15초가 지나면.
  - **자리 비움**: 얼굴이 5초 넘게 보이지 않으면 그 시간을 기록합니다.
  - 알람은 1분에 한 번까지 울립니다. 휴식 중에는 판정하지 않습니다.
- 얼굴 인식 모델은 처음 켤 때 인터넷에서 받아옵니다(jsDelivr, Google 저장소). 학교 와이파이에서 막히면 `face_landmarker.task` 파일을 받아 저장소에 `models/face_landmarker.task`로 올리면 그 파일을 먼저 씁니다.
- 영상은 기기 안에서만 분석하고 저장하거나 보내지 않습니다. 남는 것은 "자리 비움 n분, 졸음 n회" 같은 숫자뿐입니다.
- 카메라 판정은 추정값이라 틀릴 수 있습니다. 통계에서 스스로 매긴 집중도와 함께 비교해 보세요.

## 6. 아두이노 깨우기 장치 (선택)

PC의 Chrome·Edge에서 앱을 열고 **내 정보 → 아두이노 깨우기 장치 → 아두이노 연결**을 누르면, 졸음이 감지될 때 진동 모터와 부저가 울립니다.
회로와 코드는 `arduino/yaja_alarm/yaja_alarm.ino`에 있습니다. (진동 모터는 트랜지스터로 구동하고 역기전력 방지 다이오드를 꼭 다세요.)
휴대폰 브라우저는 Web Serial을 지원하지 않아 아두이노 연결은 PC에서만 됩니다.

## 7. 베타 테스트 진행 예시

1. 테스터들이 `JOIN_CODE`로 가입하고, 참여 동의서를 받습니다. 카메라를 쓰는 경우 동의서에 적어 주세요.
2. **1주차**: 각자 **내 정보 → 베타 테스트 → 실험 단계**를 **A(기록만)**로 바꿉니다. 피드백·제안·AI 멘토 없이 기록만 쌓습니다.
3. **2주차**: **B(피드백)**로 바꿉니다. 공부 피드백, 통계 제안, AI 멘토를 씁니다.
4. 선생님 화면 **내 정보 → 익명 CSV**를 내려받거나 시트의 `공부기록` 탭에서 `실험단계` 열로 A주와 B주를 나눠 할 일 달성도, 주간 목표 진행률, 계획 정확도, 집중도, 방해 요인, 졸음 감지 횟수를 비교합니다.

> 인원이 적고 대조군이 없으며, 처음 써 보는 앱이라 생기는 효과도 섞일 수 있습니다. 할 일 달성도와 집중도는 학생이 스스로 매긴 값입니다. 발표할 때 이 한계를 함께 밝혀 주세요.

## 8. 체험 모드

로그인 화면의 **학생 화면 체험하기**, **선생님 화면 체험하기**는 서버 없이 예시 데이터로 모든 화면을 보여 줍니다. 발표 시연에 쓸 수 있습니다.
체험 중 남긴 기록은 그 기기에만 저장되고, **체험 끝내기**를 누르면 지워집니다. 예시 학생과 기록은 모두 만들어 낸 데이터입니다.

## 9. 고치고 다시 올리기

GitHub 저장소에서 파일을 수정(연필 버튼)하면 1~2분 뒤 반영됩니다. 설치된 앱은 다음에 인터넷이 연결된 상태로 열 때 새 버전을 받습니다.

- 기본 과목과 방해 요인: `app.js` 위쪽의 `DEFAULT_SUBJECTS`, `DEFAULT_DISTRACTORS` (각자 내 정보에서도 바꿀 수 있음)
- 예상 시간 선택지, 주간 목표 시간 선택지: `app.js` 위쪽의 `PLAN_MIN`, `TARGET_MIN`
- 멘토의 말투와 규칙: `apps-script/Code.gs`의 `MENTOR_RULES` (고친 뒤 배포 관리에서 새 버전 배포)
- 카메라 판정 기준: `camera.js` 위쪽의 `SENS`, `AWAY_GRACE_MS`, `TILT_DEG`
