# 야자 관리실

EBS 자기주도학습센터를 이용하지 못하는 학생도 야간자율학습 시간을 관리형 독서실처럼 관리받을 수 있게 만든 웹앱입니다.
인터넷 주소로 열고 휴대폰 홈 화면에 **앱처럼 설치**해서 씁니다.

**앱 주소:** https://kdy47736190-lgtm.github.io/yaja-room/

## 기능

| 기능 | 어디에 있나 | 하는 일 |
|---|---|---|
| 1. 학습 시간 기록 | 오늘 | 할 일마다 타이머로 순공 시간과 휴식 시간을 따로 기록 |
| 2. 과목별 학습량·목표·성적 입력 | 오늘, 기록 → 성적·목표 | 과목·범위·예상 시간 계획, 내신(5등급)·모의고사(9등급, 백분위) 기록, 과목별 목표 등급 |
| 3. 집중 패턴 분석 | 점검, 보고서 | 할 일이 끝날 때 결과·집중도·방해 요인을 기록하고 시간대별 집중도, 계획 정확도를 분석 |
| 4. 카메라 학습 관리 | 타이머 화면 | 졸음(눈 감김)과 자리 비움을 감지해 소리·진동(·아두이노)으로 깨우기. 영상은 저장하지 않음 |
| 5. 분석 방식 | 앱 전체 | 숫자 계산은 투명한 규칙으로, 카메라 인식은 이미 학습된 딥러닝 모델(MediaPipe), 해석과 조언은 AI 멘토 |
| 6. AI 학습 멘토 | 멘토 | 내 기록·성적·목표를 보고 공부 방법과 시간 배분을 상담, 상담 끝에 약속을 정하고 다음 상담에서 확인 |
| 7. 주간 학습 보고서 | 보고서 | 주간 순공, 목표 달성률, 계획 정확도, 시간대별 집중도, 방해 요인, 카메라 기록, 다음 주 제안, AI 코멘트 |

## 들어 있는 파일

| 파일 | 하는 일 |
|---|---|
| `index.html`, `styles.css` | 화면 |
| `app.js` | 앱 기능 전체 |
| `camera.js` | 카메라 졸음·자리 비움 판정, 아두이노 연결 |
| `config.js` | 운영팀 서버 주소 |

| `arduino/yaja_alarm/yaja_alarm.ino` | 아두이노 깨우기 장치 코드와 회로 설명 |

## 1. 휴대폰에 앱으로 설치하기

- **안드로이드(Chrome)**: 앱의 "앱 설치하기" 버튼을 누르거나, 메뉴(⋮)에서 **앱 설치**를 고릅니다.
- **삼성 인터넷**: 주소창의 설치 아이콘을 누르거나, 메뉴에서 홈 화면에 추가합니다.
- **아이폰(Safari)**: 아래쪽 공유 버튼에서 **홈 화면에 추가**를 고릅니다. 아이폰은 Safari에서만 설치할 수 있습니다.

> 아이폰은 Safari와 홈 화면 앱의 저장 공간이 따로입니다. **먼저 설치하고, 그다음부터는 홈 화면 아이콘으로만** 쓰도록 안내해 주세요.

기록은 각자 기기 안에만 저장됩니다. 기기를 바꾸기 전에는 설정 → 백업 코드 복사로 옮길 수 있습니다.

## 2. 운영팀 서버 만들기 (구글 시트 + Apps Script)

서버 하나로 두 가지를 합니다. **① 베타 테스트 기록 자동 수집**, **② AI 멘토 연결**.

1. 구글 시트를 새로 만듭니다(예: `야자 관리실 운영`).
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 원래 있던 코드를 모두 지우고 `apps-script/Code.gs` 내용을 붙여 넣은 뒤 저장합니다.
4. 오른쪽 위 **배포 → 새 배포** → 유형 선택(톱니)에서 **웹 앱**을 고릅니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포**를 누르고 권한을 허용합니다. "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 누릅니다.
6. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다. 브라우저로 이 주소를 열어 `수집 주소가 정상적으로 동작하고 있어요`가 보이면 성공입니다.
7. GitHub 저장소에서 `config.js`를 열고 연필(편집) 버튼을 눌러 `serverUrl: ''`의 따옴표 안에 주소를 붙여 넣은 뒤 **Commit changes**를 누릅니다.

> `Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포**를 해야 같은 주소에 반영됩니다.

### ① 베타 테스트 기록 받기

테스터는 앱 **설정**에서 참여 코드를 넣고 **내 기록을 운영팀 구글 시트로 보내기**를 켭니다.
시트에 `점검기록`(타이머 한 번 = 한 줄)과 `할일`(계획 한 개 = 한 줄) 탭이 자동으로 생깁니다.
같은 기록은 한 번만 들어가고, 인터넷이 끊겼을 때 저장한 기록은 다시 연결되면 보내집니다.

### ② AI 멘토 연결

멘토는 Claude API를 씁니다. **API 키는 Apps Script의 '스크립트 속성'에만 넣고, 앱 파일이나 GitHub에는 절대 넣지 마세요.** (GitHub에 올리면 누구나 키를 볼 수 있습니다.)

1. API 계정과 결제는 **선생님(성인)이** 만들어 주세요. Anthropic 서비스는 만 18세 미만이 직접 쓸 수 없고, 미성년자가 쓰는 서비스에 API를 넣을 때는 안전장치와 'AI를 쓴다는 사실 고지'가 필요합니다. 이 앱은 첫 사용 때 무엇이 AI로 전달되는지 알리고 동의를 받으며, 멘토 규칙에 위기 상황 안내(109, 1388, Wee클래스)를 넣어 두었습니다.
2. Apps Script 편집기 왼쪽 **프로젝트 설정(톱니)** → 아래쪽 **스크립트 속성** → **스크립트 속성 추가**에서 다음을 넣습니다.

| 속성 | 값 | 필수 |
|---|---|---|
| `ANTHROPIC_API_KEY` | Claude API 키 | 필수 |
| `MENTOR_CODE` | 멘토 이용 코드 (정하면 앱 설정에 같은 코드를 넣은 사람만 사용) | 권장 |
| `MENTOR_DAILY_LIMIT` | 기기 하나가 하루에 보낼 수 있는 질문 수 (기본 30) | 선택 |
| `MENTOR_GLOBAL_LIMIT` | 전체 하루 질문 수 (기본 400) | 선택 |
| `MENTOR_MODEL` | 사용할 모델 (기본 `claude-haiku-5-5`) | 선택 |

3. 브라우저로 웹 앱 URL을 열었을 때 `"mentor":"ready"`가 보이면 연결된 것입니다.
4. 사용량만큼 요금이 나오므로, 하루 제한 값을 학교 예산에 맞게 정하세요.

멘토에게 전달되는 것: 과목, 할 일 제목, 예상·실제 시간, 결과, 집중도, 방해 요인, 시간대별 집중도, 카메라 판정 횟수, 성적과 목표 등급, 지난 상담 요약과 약속, 멘토에게 쓴 대화.
**이름·닉네임·점검 메모·카메라 영상은 보내지 않고, 대화 내용은 시트에 저장하지 않습니다.**

## 3. 카메라 관리

- 타이머 화면의 **카메라 관리 켜기**를 누르면 앞쪽 카메라로 얼굴을 확인합니다. https 주소에서만 동작합니다.
- 판정 기준(설정에서 민감도 변경 가능)
  - **졸음**: 눈 감김 점수가 기준을 넘은 상태가 3초(보통) 이어지면. 고개를 25도 넘게 숙이고 있으면(필기 중일 수 있음) 3배 더 오래 지켜본 뒤 판정합니다.
  - **엎드림**: 고개를 숙이거나 눈이 감기다가 얼굴이 사라진 채 15초가 지나면.
  - **자리 비움**: 얼굴이 5초 넘게 보이지 않으면 그 시간을 기록합니다.
  - 알람은 1분에 한 번까지 울립니다. 휴식 중에는 판정하지 않습니다.
- 얼굴 인식 모델은 처음 켤 때 인터넷에서 받아옵니다(jsDelivr, Google 저장소). 학교 와이파이에서 막히면 `face_landmarker.task` 파일을 받아 저장소에 `models/face_landmarker.task`로 올리면 그 파일을 먼저 씁니다.
- 영상은 기기 안에서만 분석하고 저장하거나 보내지 않습니다. 남는 것은 "자리 비움 n분, 졸음 n회" 같은 숫자뿐입니다.
- 카메라 판정은 추정값이라 틀릴 수 있습니다. 보고서에서 스스로 매긴 집중도와 함께 비교해 보세요.

## 4. 아두이노 깨우기 장치 (선택)

PC의 Chrome·Edge에서 앱을 열고 **설정 → 카메라 관리 → 아두이노 연결**을 누르면, 졸음이 감지될 때 진동 모터와 부저가 울립니다.
회로와 코드는 `arduino/yaja_alarm/yaja_alarm.ino`에 있습니다. (진동 모터는 트랜지스터로 구동하고 역기전력 방지 다이오드를 꼭 다세요.)
휴대폰 브라우저는 Web Serial을 지원하지 않아 아두이노 연결은 PC에서만 됩니다.

## 5. 베타 테스트 진행 예시

1. 테스터마다 참여 코드(T01, T02 …)를 정하고 참여 동의서를 받습니다. 카메라를 쓰는 경우 동의서에 적어 주세요.
2. **1주차**: 설정 → 실험 단계 **A주: 기록만**. 보고서·피드백·AI 멘토 없이 기록만 쌓습니다.
3. **2주차**: **B주: 피드백**. 점검 피드백, 주간 보고서, AI 멘토를 씁니다.
4. 시트의 `실험단계` 열로 A주와 B주를 나눠 목표 달성률, 계획 정확도, 집중도, 방해 요인, 졸음 감지 횟수를 비교합니다.

> 인원이 적고 대조군이 없으며, 처음 써 보는 앱이라 생기는 효과도 섞일 수 있습니다. 발표할 때 이 한계를 함께 밝혀 주세요.

## 6. 고치고 다시 올리기

GitHub 저장소에서 파일을 수정(연필 버튼)하면 1~2분 뒤 반영됩니다. 설치된 앱은 다음에 인터넷이 연결된 상태로 열 때 새 버전을 받습니다.

- 기본 과목과 방해 요인: `app.js` 위쪽의 `DEFAULT_SUBJECTS`, `DEFAULT_DISTRACTORS` (각자 설정 화면에서도 바꿀 수 있음)
- 멘토의 말투와 규칙: `apps-script/Code.gs`의 `MENTOR_RULES`
- 카메라 판정 기준: `camera.js` 위쪽의 `SENS`, `AWAY_GRACE_MS`, `TILT_DEG`

## 7. (선택) 안드로이드 앱 파일로 만들기

PWABuilder(pwabuilder.com)에 앱 주소를 넣으면 안드로이드 앱 패키지로 만들 수 있습니다.
Play 스토어에 올리려면 Google Play 개발자 계정(유료)과 심사가 필요합니다. 학교 안 베타 테스트라면 홈 화면 설치만으로 충분합니다.
